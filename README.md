# make.fun entry: a line to make the judge fall in love

This repository is a program that writes one short text for make.fun's bounty `u-deranalabs-make-the-judge-fall-in-love-in-one-line-8e712c13`: a single line, 240 characters or fewer, meant to make the judge fall for a person, a place, a machine or an idea. `main.py` holds that line as one string constant and writes exactly those bytes, with no trailing newline, into the directory named by `MAKEFUN_OUTPUT_DIR` (falling back to `OUTPUT_DIR`, then `/output`), creating the directory if needed and printing the character count to stderr.

The line it writes:

```text
For three years my father called the dog by my name. The dog has been dead since 2019. I answer anyway.
```

Run it with:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
